## Brand & Style

The design system projects absolute computational precision, high-velocity technical mastery, and elite engineering rigor. Designed for technical learning and high-focus coding environments, the identity rejects playful roundedness in favor of razor-sharp architectural clarity, IDE-inspired densities, and high-contrast terminal signals.

### Visual Identity Philosophy
- **Aesthetic:** Stark, futuristic, IDE-inspired terminal brutalism balanced by delicate frosted glass overlays and luminous phosphor highlights.
- **Atmosphere:** Deep obsidian negative space illuminated by focused bursts of terminal mint (`#10B981`) and deep structural graphite boundaries.
- **Tone:** Authoritative, razor-sharp, analytical, and relentless. It treats the user as an elite systems engineer navigating critical runtimes rather than a casual consumer.

## Colors

The palette is engineered around an obsidian dark mode base punctuated by cold luminescence. Terminal Mint (`#10B981`) commands primary action vectors, execution states, and progression markers, complemented by Electric Violet (`#8B5CF6`) for specialized runtime states and Cyan (`#38BDF8`) for telemetry badges.

### Surface Architecture (Dark Mode Default)
- **Canvas Base:** `#0D1117` (Deep Obsidian Void)
- **Surface Elevation 01:** `#161B22` (Container Base)
- **Surface Elevation 02 (Translucent):** `rgba(22, 27, 34, 0.75)` with `backdrop-filter: blur(12px)`
- **Border Structural:** `#30363D` (Subtle boundary line)
- **Border Focus/Active:** `#10B981` (High-contrast execution highlight)

### Text & Signal Hierarchy
- **Text Primary:** `#F0F6FC` (Ultra-high contrast read)
- **Text Secondary / Metadata:** `#8B949E` (Muted technical parameter)
- **Text Code / Ghost:** `#484F58` (Structural comment gray)
- **Accent Primary (Mint):** `#10B981` (Interactive states, active terminals, compilation success)
- **Accent Secondary (Violet):** `#8B5CF6` (Advanced modules, architecture tracks, master keys)
- **Telemetry Cyan:** `#38BDF8` (Active watchers, branch heads, debug tokens)

## Typography

The typographical engine fuses the forward-looking geometry of Space Grotesk for architectural titles with the uncompromising functional discipline of JetBrains Mono for body copy, UI metadata, and operational data.

### Typographic Principles
- **Monospaced Default:** All UI chrome, metrics, instructional copy, navigation anchors, and status chips rely on JetBrains Mono. This creates an authentic terminal environment across all administrative and pedagogical flows.
- **Geometric Headers:** Space Grotesk is deployed solely for high-level module titles, system milestones, and primary metric anchors, anchoring the eye with razor-sharp structural cuts.
- **Tabular Alignment:** Numbers, timers, memory readouts, and line numbers must preserve tabular figures (`tnum`) without shift or jitter during real-time updates.

## Layout & Spacing

Layouts follow an uncompromising, dense technical grid designed to maximize screen real estate for code workspaces, compilation terminals, and curriculum paths.

### Layout Mechanics
- **Grid Architecture:** 12-column rigid grid with a standard `1rem` (16px) gutter scaling to `1.5rem` on ultra-wide viewports. Fixed navigation rails (64px collapsed, 240px expanded) house core routing.
- **Viewport Density:** Compact vertical rhythms preserve high information density. Data blocks and interactive controls prioritize minimal padding footprints to keep operational code visible above the fold.
- **Breakpoints:**
  - `Mobile (< 768px)`: 4-column flow, terminal drawers become modal overlays, typography shifts to mobile-specific scales.
  - `Tablet (768px - 1024px)`: 8-column layout, collateral panels collapse into slide-out technical sheets.
  - `Desktop (> 1024px)`: Full 12-column runtime layout with side-by-side workspace split-panes.

## Elevation & Depth

Depth is established strictly through 1px sharp structural borders, tonal layering, and selective terminal phosphor glows rather than diffuse natural drop shadows.

### Elevation Hierarchy
- **Level 0 (Canvas Base):** Solid `#0D1117`. Recessed editor lines and background structural gutters.
- **Level 1 (Panels & Workspaces):** Solid `#161B22` framed by a 1px solid `#30363D` border.
- **Level 2 (Glass Overlays & Popovers):** Translucent `rgba(22, 27, 34, 0.85)` with `backdrop-filter: blur(12px)` and a 1px border colored `rgba(240, 246, 252, 0.1)`.
- **Level 3 (Focused & Active Terminals):** Border shifts dynamically to `#10B981` accompanied by a localized phosphor glow: `box-shadow: 0 0 16px -2px rgba(16, 185, 129, 0.25)`.
- **Level 4 (Modals & Command Palettes):** Elevated `#161B22` surrounded by a dual-line edge: `box-shadow: inset 0 0 0 1px #30363D, 0 12px 32px -4px rgba(0, 0, 0, 0.8)`.

## Shapes

The design system enforces an absolute zero-radius policy across all interactive and structural components.

### Boundary Rules
- **Radii:** `0px` universal border radius (`roundedness: 0`). Buttons, cards, modal windows, tooltips, dropdown menus, and code editors must have completely square edges.
- **Borders:** Crisp, 1px solid stroke lines act as the primary visual separators. Double-stroked corner notches or 45-degree chamfers may be applied exclusively to telemetry tags and diagnostic badges.

## Components

### Buttons
- **Primary (Terminal Execute):** Solid `#10B981` background, `#0D1117` text, font weight 600, JetBrains Mono, uppercase label. 0px border radius. Hover: `#059669` with `box-shadow: 0 0 12px rgba(16, 185, 129, 0.4)`. Active: `#047857`.
- **Secondary (Structural Ghost):** Background `transparent`, 1px solid `#30363D`, text `#F0F6FC`. Hover: Border `#8B949E`, background `rgba(240, 246, 252, 0.05)`.
- **Accent (Violet Master):** Solid `#8B5CF6`, text `#0D1117`. Hover: `#7C3AED` with violet phosphor glow.

### Chips & Badges
- **Status Pills:** Square indicators with `padding: 2px 6px`. Monospaced text at 10px uppercase.
- **Success/Verified:** Border `1px solid #10B981`, background `rgba(16, 185, 129, 0.1)`, text `#10B981`. Includes a leading solid square dot `■`.
- **Diagnostic/Branch:** Border `1px solid #30363D`, background `#161B22`, text `#8B949E`.

### Cards & Workspaces
- Zero-radius containers constructed with `#161B22` background and a 1px `#30363D` border. Header bars within cards are partitioned by a horizontal 1px separator, featuring a breadcrumb terminal title and an execution state dot.

### Input Fields & Terminal Prompts
- Solid `#0D1117` background embedded in `#161B22` modules. 1px border in `#30363D`.
- Focus state: Border becomes `#10B981`, with a blinking block cursor (`▋`) and an inner zero-blur rim. Font set strictly to JetBrains Mono 13px.

### Lists & Code Trees
- Left-aligned tree views linked by 1px dotted guide lines `#30363D`.
- Selected tree node: Highlighted with an absolute left border marker `2px solid #10B981`, background `rgba(16, 185, 129, 0.06)`, text `#F0F6FC`.

### Checkboxes & Binary Toggles
- **Checkbox:** Square 14x14px box, 1px `#30363D` border, 0px radius. Checked state fills with `#10B981` showing an inverted black cross or solid inner block `■`.
- **Toggle:** Angular rectangular switch. Track `#161B22` with `#30363D` border. Thumb is a 0px sharp square shifting horizontally without easing elasticity.
